# 사나이청소기 · SANAI CLEANER v0.1.0-alpha

Android 11 이상. 네이티브 Java 앱, 검정/빨강/흑백 채드 테마.

## 구현 범위
- MediaStore 기반 사진·동영상·음악 스캔, SAF 폴더의 일반 파일 검색.
- SHA-256 완전 중복 그룹, 이미지 dHash/색상/밝기/선명도 비교, 동영상 5개 샘플 프레임 비교.
- ML Kit 번들 모델 기반 이미지 라벨 및 한글 스크린샷 OCR, 로컬 SQLite 캐시.
- 유사 사진/동영상/지원 문서·압축파일 그룹, 보관 추천, 원본 미리보기, 검색.
- 중요 파일 보호, 시스템 휴지통 승인 요청, 일반 파일 격리 및 복원, 사용 빈도 낮은 앱 설정, 위젯 2×2/4×2.
- 보호 기록 기반 단순 점수 조정. 외부 사진 전송 없음.

## 한계 및 안전
추천 점수는 삭제 안전 확률이 아니다. 반드시 직접 검토한다. 다른 앱의 비공개 데이터/캐시 및 시스템 파일은 직접 접근할 수 없다. 일반 파일은 사용자 선택 폴더만 분석하며 Android 제한으로 Download 루트 등의 선택이 불가능할 수 있다. 사진 및 영상은 MediaStore 권한 범위 내에서만 분석한다. 유사도는 근사 비교이며 모든 유사 파일을 찾는 것을 보장하지 않는다. 일반 파일 격리본은 앱 삭제 시 사라진다. 휴지통 및 격리만으로 즉시 공간이 확보되지 않는다. 실기기 검증 전에는 중요 파일을 정리하지 않는다.

아직 미구현: 영상 압축, 예약 스캔, 스와이프 전용 UI, 고급 의미 분석, 청소 애니메이션/효과음, 안정적인 서명 기반 업데이트. 이 버전은 알파 테스트용이다. 아이콘은 확정 디자인을 128px WebP로 축소한 리소스.

## 빌드
JDK 17, Gradle 8.11.1, Android SDK 35. `gradle :app:assembleDebug :app:lintDebug`
GitHub Actions의 Build Android APK에서 산출물을 확인한다. 빌드 및 lint 통과 시 테스트용 APK를 prerelease로 게시한다. 디버그 서명은 러너마다 달라질 수 있어 이후 버전 덮어쓰기 설치를 보장하지 않는다. 운영용 고정 서명은 별도로 설정해야 한다.
